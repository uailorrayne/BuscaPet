SISTEMA PARA LOCALIZAÇÃO DE ANIMAIS DESAPARECIDOS.

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Sistemas de Informação da UNIUBE.

O sistema tem como objetivo facilitar o encontro de animais perdidos e encontrados, permitindo o cadastro de usuários, publicação de animais, comunicação entre usuários e localização através da API do Google Maps.

## Funcionalidades

- Cadastro de usuários
- Login
- Perfil de usuário
- Cadastro de animais
- Edição de anúncios
- Upload de imagens
- Chat entre usuários
- Conversas privadas
- Geolocalização
- Google Maps
- Banco de dados relacional
